管理员登录

控制台只对管理员开放。非管理员账号可以登录 DSH 客户端安装插件，但进不来这里。

设置新密码

首次登录（或管理员重置后）的强制步骤。至少 12 位。

需要管理员权限

账号与权限只能由管理员在这里配置。请在服务端用 CLI 把自己提升为管理员：
node server/cli.mjs grant:add --user <你的用户名> --pattern '*' --effect allow
或建一个管理员账号：node server/cli.mjs user:add --username admin --admin
权限模型：用户 → 组 → 插件规则。规则用 glob（如 @dsh-internal/dsh-plugin-*）。默认拒绝：没有任何规则授予就不能安装； 命中 deny 时 deny 优先。这些判定全部在服务端，客户端页面改不了。

已有规则

DSH 账号与市场账号是一对一绑定：一个 DSH 账号只能绑一个市场账号， 反过来一个市场账号也只能绑一个 DSH 账号。两个方向都受限，所以冲突提示会指出是哪一侧被占用。
绑定由用户在 DSH 安装页自行完成（登录后点按钮，不会自动绑定）； 用户也可以自己解绑。这里用于查看，以及处理用户自己动不了的情况—— 账号主人已离职、市场账号要改派。 同一对重复绑定是幂等的（刷新页面不会报错）。
CLI：node server/cli.mjs bind:list / bind:rm --user <市场账号> / bind:rm --dsh-user <DSH 账号 ID>
